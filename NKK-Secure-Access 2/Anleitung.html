NKK Secure Access

Dein sicherer Zugang zum NKK Firmennetz

Installationsanleitung
1

ZIP entpacken

Öffne die Datei NKK-Secure-Access.zip aus der Mail. Das Passwort ist nkk (kleingeschrieben).

2

Installer starten

Doppelklick auf NKK Secure Access Setup.exe und den Installer durchklicken.

3

App öffnen

Im Startmenü unter KronSolutions → NKK Secure Access die App starten.

4

Aktivierungsschlüssel eingeben

Den Schlüssel aus der zweiten Mail eingeben und auf Aktivieren klicken.

5

Arbeiten

Auf Terminalserver 2 klicken — der Arbeitsplatz öffnet sich wie gewohnt.

Gut zu wissen

  • Die App startet nicht automatisch. Falls gewünscht: Einstellungen (Zahnrad oben rechts) → „Beim Anmelden starten"
  • Updates kommen automatisch — du musst nichts manuell machen
  • Das rote NKK Symbol erscheint unten rechts in der Taskleiste
Windows Warnung? Falls eine blaue Meldung erscheint: auf „Weitere Informationen" klicken, dann auf „Trotzdem ausführen". Kommt nur beim ersten Mal.

Bei Problemen

In der App: Headphones Icon oben rechts → „Diagnose für Support kopieren" → per Mail schicken an:
