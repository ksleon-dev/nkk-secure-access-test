Secure Access

Installationsanleitung
Version 0.2.0

Installation

Einmalig, dauert 2 Minuten

Wichtig: Alter VPN Client

Bitte den bisherigen VPN Client beenden und deaktivieren bevor ihr startet. Deinstallieren ist erstmal nicht nötig, er bleibt noch aktiv. Wir bitten euch aber, auf den neuen Client umzusteigen.

1

ZIP entpacken

Öffne NKK-Secure-Access.zip aus der Mail. Passwort: nkk

2

Installer starten

NKK Secure Access Setup.exe
Doppelklick zum Starten

Einfach auf Weiter klicken — alles wird automatisch eingerichtet.

Blaue Windows Warnung?

Klick auf „Weitere Informationen" → „Trotzdem ausführen". Kommt nur einmal.

3

App öffnen & Schlüssel eingeben

Startmenü → KronSolutions → NKK Secure Access. Schlüssel aus der zweiten Mail einfügen.

Aktivierungsschlüssel eingeben — nur beim ersten Start
4

Arbeiten!

Auf Terminalserver 2 klicken — dein Arbeitsplatz öffnet sich.

Geschafft!

Grüne Leiste unten = verbunden. Ab jetzt reicht ein Klick.

Das kann die App

Alles auf einen Blick

Hauptbildschirm

Euer täglicher Startpunkt:

  • Terminalserver 2 — Standard Arbeitsplatz
  • Terminalserver 1 — Spezialanwendungen
  • Grüne Leiste = Verbindung steht
  • Uhrzeit & Datum oben links

Aktuelles

Zeitungs-Icon oben rechts:

  • Ankündigungen vom IT Team
  • Updates mit Neuerungen
  • Möglichkeit für Feedback

Diagnose

Headphones-Icon oben rechts:

  • Ping & Speed Test auf Knopfdruck
  • Smart Debug — repariert Probleme automatisch
  • Diagnose kopieren — alles für den Support in einem Klick

Einstellungen

Zahnrad-Icon oben rechts:

  • Autostart bei Windows Login (optional)
  • Anmeldedaten verschlüsselt speichern
  • Logs für den Support einsehen

Gut zu wissen

⚙️ Autostart

Startet nicht automatisch. In den Einstellungen aktivierbar.

🔄 Updates

Kommen automatisch. Ihr müsst nichts machen.

🔴 Tray Icon

Rotes NKK Symbol unten rechts in der Taskleiste. Rechtsklick = Schnellzugriff.

🟢 Statusleiste

Grün = verbunden. Rot = auf „Verbinden" klicken.

Häufige Fragen

Verbindung bricht ab?

Statusleiste wechselt auf Rot.

→ „Verbinden" klicken. Hilft nicht? Diagnose → Smart Debug.

Terminalserver reagiert nicht?

Erst prüfen ob die Leiste grün ist.

→ Falls grün und trotzdem Fehler: Diagnose → Smart Debug.

Schlüssel vergessen?

Wird nur einmal benötigt.

→ Mail an support@ticket.kronsolutions.de — wir schicken einen neuen.

App startet nicht?

→ Rechner neu starten. Hilft nicht? Installer nochmal ausführen.

Wir helfen sofort

Headphones Icon in der App → „Diagnose kopieren" → per Mail an:

support@ticket.kronsolutions.de
