Installationsanleitung
Dein sicherer Zugang zum NKK Firmennetz

Installation

1

ZIP entpacken

Öffne die Datei NKK-Secure-Access.zip aus der Mail.
Das Passwort lautet: nkk (kleingeschrieben).

📁
ZIP Inhalt: Setup.exe + Anleitung.html
2

Installer starten

Doppelklick auf NKK Secure Access Setup.exe.
Der Installer richtet alles automatisch ein — einfach auf Weiter klicken.

Windows zeigt eine blaue Warnung?

Das ist normal bei neuer Software. Klicke auf „Weitere Informationen" (kleiner blauer Text), dann auf „Trotzdem ausführen". Das kommt nur beim ersten Mal.

🖥️
NSIS Installer Wizard
Der Installer installiert automatisch alle nötigen Komponenten
3

App öffnen

Im Startmenü unter KronSolutions → NKK Secure Access die App starten.
Das rote NKK Symbol erscheint auch unten rechts in der Taskleiste.

4

Aktivierungsschlüssel eingeben

Den Schlüssel aus der zweiten Mail in das Eingabefeld kopieren und auf Aktivieren klicken.

Den Aktivierungsschlüssel aus der zweiten Mail eingeben
5

Fertig! Arbeiten.

Klicke auf Terminalserver 2 — dein gewohnter Arbeitsplatz öffnet sich.

Geschafft!

Ab jetzt reicht ein Klick auf den Terminalserver Button um wie gewohnt zu arbeiten.

✅
Hauptbildschirm — verbunden und bereit
Grüne Leiste unten = Verbindung steht
💡

Tipps & Hinweise

⚙️

Autostart

Die App startet nicht automatisch. Falls gewünscht: Einstellungen (Zahnrad oben rechts) → „Beim Anmelden starten" aktivieren.

🔄

Updates

Die App aktualisiert sich automatisch. Ihr müsst nichts manuell machen — es erscheint einfach eine kurze Meldung.

🔴

Tray Icon

Das rote NKK Symbol lebt unten rechts in der Taskleiste. Rechtsklick für Schnellzugriff auf den Terminalserver.

📰

Neuigkeiten

Über das Zeitungs-Icon oben rechts seht ihr aktuelle Infos und Änderungen am Programm.

🔧

Häufige Fragen

Die Verbindung bricht ab

Die Statusleiste unten wechselt von Grün auf Rot.

→ Auf „Verbinden" klicken. Falls das nicht hilft: Einstellungen → Diagnose → „Smart Debug" klicken — das repariert die meisten Probleme automatisch.

Der Terminalserver reagiert nicht

Klick auf „Terminalserver 2" passiert nichts oder es kommt ein Fehler.

→ Prüfe ob die Statusleiste grün ist (= verbunden). Falls nicht, erst verbinden. Falls ja: Diagnose → Smart Debug klicken.

Ich habe meinen Schlüssel vergessen

Der Aktivierungsschlüssel wird nur einmal benötigt.

→ Falls ihr euch erneut aktivieren müsst, meldet euch bei support@ticket.kronsolutions.de — wir schicken einen neuen.

Die App startet nicht

Beim Öffnen passiert gar nichts.

→ Rechner neu starten und nochmal versuchen. Falls es weiterhin nicht geht: Installer erneut ausführen.

Wir helfen sofort

In der App: Headphones Icon oben rechts → „Diagnose für Support kopieren" → per Mail schicken an:

support@ticket.kronsolutions.de
